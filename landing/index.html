How it works

Four steps. All observable.

  1. 01

    Inspect

    Deterministic detection runs in your browser — emails, phone numbers, IPs, credentials, custom terms. Nothing leaves the tab.

  2. 02

    Redact

    An editable preview replaces each value with a reversible placeholder like [EMAIL_1]. Toggle findings on or off.

  3. 03

    Route

    Choose local-first, local-only, or deep cloud inference. Cloud paths require your explicit consent before any request.

  4. 04

    Observe

    The SDK reports the real inferenceSource, latency and fallback — so you see where it actually ran, not where you asked.

Privacy by construction

What stays private, and how

Local airlock

All detection and replacement happens synchronously in the browser, before any request is built. The model never sees raw values.

Sanitized-only inference

The prompt builder receives the sanitized string only. A defensive check rejects any payload that still contains a masked original.

Memory-only vault

The placeholder-to-value mapping lives in memory and is never persisted — no database, no storage, no server-side content.

Inference modes

You decide where the thinking happens

Local

Local-first hybrid

Tries Gemini Nano on your device first, falling back to the cloud only with consent. Fallback is always reported.

On-device

Local-only private

Locks inference to the device. If no local model is available, it fails closed with a clear message — never escalates to the cloud.

Cloud

Deep cloud synthesis

A structured JSON report after your explicit confirmation. The sanitized string is the only content sent.

FAQ

Questions, answered

Does ClipShield store my documents?

No. Everything stays in your browser tab. There is no database write, no local storage, and no server-side persistence of content in this build.

Where does inference actually run?

You choose the mode, but ClipShield reports the real source returned by the SDK — on_device or in_cloud — so you see what happened, not just what you requested.

Do I need special hardware for on-device inference?

On-device inference needs Chrome desktop 139+ with the Prompt API enabled, and enough disk and memory for Gemini Nano. Without it, ClipShield offers the cloud path instead.

Is detection perfect?

No. Detection is best-effort pattern matching and always needs human review. ClipShield is not a certified security or zero-trust product.

Can I use it without an account?

Yes — during the #BuildHybridAI 2026 judging window the workspace is open with no sign-in required. This temporary open access is removed after judging concludes.
